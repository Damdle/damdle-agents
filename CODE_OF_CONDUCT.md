# Community Code of Conduct

We want Damdle Agents to be a welcoming, practical place for people with different backgrounds and experience levels to build together.

## Expected behavior

- Be respectful, constructive, and considerate.
- Critique ideas and code without attacking people.
- Welcome questions and explain decisions clearly.
- Respect privacy and do not share another person's private information.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, and sustained disruption are not acceptable.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainers using the contact method listed in the public repository. Maintainers may edit or remove contributions and may restrict participation when needed. The public repository must name a verified reporting contact before it invites community participation.
